# Portraits des personnages — Les Liens d'Ayanokoji

Dépose ici une image par personnage. Le nom du fichier est la colonne « Fichier », suivi de `.jpg`, `.png` ou `.webp` : par exemple `kakashi.jpg`.

L'image apparaît toute seule sur la carte du personnage, dans toutes les manches où il figure. Un personnage sans image garde une carte avec son initiale.

Conseil : un portrait cadré sur le visage, à peu près carré ou en hauteur, d'au moins 400 pixels de large.
